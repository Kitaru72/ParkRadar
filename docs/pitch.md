# Короткий питч

ParkRadar - это сервис оценки свободных парковочных мест по адресу на основе анализа публичных камер.

Мы решаем очень человеческую проблему: человек тратит время, нервы и топливо на поиск парковки рядом с домом или нужной точкой.

Вместо установки нового железа мы используем уже существующие публичные камеры и превращаем их в продуктовый сервис.

Для пользователя это выглядит очень просто: он вводит адрес, получает количество свободных мест в радиусе до 1 км, видит распределение по классам машин и может включить мониторинг поездки, чтобы availability обновлялась по мере приближения.

Для администратора у нас есть отдельный защищенный контур: реестр камер, test-mode ingestion, статистика запросов и ручной контроль статусов.

Сегодня мы показываем рабочий MVP, который строго соответствует ТЗ и уже готов к переходу из test mode в pilot production.
