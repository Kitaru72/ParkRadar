# Сценарий демо на 5-7 минут

## 1. Открытие

Проблема простая: человек хочет понять, есть ли парковка рядом с нужным адресом, не тратя время на круги по двору.

## 2. Пользовательский сценарий

1. Открыть главную страницу.
2. Ввести `Екатеринбург, улица Малышева 51`.
3. Показать:
   - итоговое количество свободных мест
   - availability bucket
   - классы машин
   - ближайшие источники данных
4. Сказать, что пользователь не видит видеопотоки и первичные кадры.

## 3. Trip Monitoring

1. Нажать `Запустить мониторинг`.
2. Показать, что создается trip-сессия.
3. Открыть блок уведомлений.
4. Объяснить, что в проде здесь возможен push, а в MVP уже есть pull fallback.

## 4. Админский сценарий

1. Перейти в админку.
2. Показать вход администратора.
3. Открыть реестр камер.
4. Загрузить новый snapshot или обновить значения `free_*`.
5. Нажать `Run due-check`.

## 5. Возврат к пользователю

1. Вернуться на главную.
2. Нажать `Обновить уведомления`.
3. Показать, что система зафиксировала изменение availability.

## 6. Закрытие

Сформулировать вывод:

Мы не ставим новое железо и не заставляем пользователя смотреть камеры. Мы превращаем уже существующую визуальную инфраструктуру в удобный сервис принятия решения.
