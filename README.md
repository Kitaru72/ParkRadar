# ParkRadar

ParkRadar - хакатонный MVP сервиса оценки свободных парковочных мест по адресу на основе анализа скриншотов с публичных камер.

## Что внутри

- Aiohttp backend с SQLite
- Адаптивный PWA-интерфейс для пользователя и администратора
- Test-mode ingestion для загрузки скриншотов и ручного ввода доступности
- Trip monitoring со встроенным scheduler
- Демо-данные, сценарий защиты и материалы презентации

## Ключевая идея

Пользователь не смотрит видео и не изучает камеры. Он получает простой ответ: есть ли свободные места рядом с нужным адресом и как ситуация меняется по мере поездки.

## MVP-контур

- поиск парковки по адресу или ссылке из карт
- агрегация свободных мест в радиусе до 1 км
- распределение по классам машин
- trip monitoring и уведомления
- admin UI и авторизация
- ingestion API для тестового режима

## Быстрый старт

1. `python -m venv .venv`
2. `.venv\Scripts\Activate.ps1`
3. `pip install -r requirements.txt`
4. `python -m app.main`

После запуска:

- пользовательский интерфейс: `http://127.0.0.1:8000/`
- админка: `http://127.0.0.1:8000/admin`
- health-check: `http://127.0.0.1:8000/health`

## Как показать изменения availability

1. На главной странице выполните поиск по демо-адресу.
2. Запустите trip monitoring.
3. В админке загрузите новый snapshot или измените значения `free_*`.
4. Нажмите `Run due-check`.
5. Вернитесь на главную и обновите уведомления.
